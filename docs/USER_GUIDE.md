# 客户跟进助手使用说明书

版本：v2.1（Android）
适用对象：单人外贸销售、业务负责人及在同一设备上查看进度的管理人员

## 1. 应用简介

“客户跟进助手”是一款本地 CRM。它以“客户 + 项目”为主线，帮助记录客户资料、联系人、沟通历史和业务节点，并把下一步行动集中到“今日”页面。

- **无需登录**：不需要账号，也不依赖网络或云服务。
- **本地存储**：业务数据保存在当前手机中；卸载应用或清除应用数据可能导致数据丢失。
- **四个工作区**：今日、客户、漏斗、我的。
- **可导出和备份**：支持 Excel 导出，以及包含附件的完整备份。

## 2. 界面导航

底部导航栏包含四个入口：

| 入口 | 用途 |
|---|---|
| **今日** | 查看逾期和今天到期的跟进任务，完成或取消任务。打开应用默认进入这里。 |
| **客户** | 搜索、筛选和新建客户；进入客户详情维护联系人、项目和所有业务记录。 |
| **漏斗** | 查看客户数量、等级、项目阶段、金额统计和业务异常入口。 |
| **我的** | 提醒权限、提醒记录、自检、示例数据、Excel 导出、备份与恢复。 |

## 3. 推荐使用流程

1. 在“客户”中新建客户。
2. 进入客户详情，补充联系人并新建一个或多个项目。
3. 在项目下录入报价、样品、注册、招标或订单等业务节点。
4. 每次沟通后点击“记录跟进”，填写反馈、阶段、下一步行动和下次跟进日期。
5. 每天从“今日”处理任务；完成后任务会保留在历史中。
6. 定期在“我的”中导出 Excel，并将完整备份保存到其他位置。

“今日”首页上方固定提供 **新建客户、客户列表、导入客户** 三个高频入口；没有待办时也会显示，不需要先理解底部导航。

## 4. 客户管理

### 4.1 新建客户

1. 点击 **客户**，点击右下角新增按钮。
2. 填写客户名称（必填）；需要时展开“更多信息”，补充阶段、客户等级、标签和备注。
3. 点击“保存”。创建成功后可选择“查看客户”或“记录首条跟进”。

客户等级为 A、B、C、D 四档，可用于排序和日常优先级判断。一个客户可以拥有多个联系人和多个项目。

### 4.2 客户详情

在客户列表点击客户进入详情页：

- **快捷操作**：客户资料下方固定显示“联系人、项目、业务、订单”四个入口。新增报价、样品、注册或招标不需要先滚到项目卡片；点击“业务”后在同一面板选择项目和记录类型。没有项目时会引导先创建项目。
- **四个页签**：概览查看客户资料与联系人；项目查看销售阶段、投入状态和下一步；业务维护报价、样品、注册、招标和订单；动态查看跟进计划与沟通历史。从提醒进入时会直接打开动态页签。

- **编辑客户**：修改基础资料、阶段、等级、标签和备注。
- **联系人**：添加或编辑联系人；可标记“决策人”，并维护邮箱、WhatsApp、沟通偏好和备注。联系人使用独立页面，长表单底部始终可以保存。
- **项目**：一个产品机会建立一个独立项目，避免不同产品的报价和阶段互相覆盖。
- **跟进记录**：按时间查看历史，历史记录应通过新增跟进追加，不用编辑旧记录替代。
- **业务记录**：点击报价、样品、注册或招标行进入维护页面。页面顶部会显示当前记录和状态，并直接提供“附件（数量）”与“删除记录”；主要保存按钮固定在页面底部，不必滚到表单末尾。报价金额和版本保持不变，只在结果页更新“客户已收到、反馈、下次跟进和结果”；价格变化使用“基于此报价新增版本”。样品可直接推进准备、寄出、签收、测试和结果节点；注册与招标支持加载已有记录后编辑。订单可在客户快捷操作中新增。
- **未保存修改保护**：在客户、联系人、项目、跟进、订单、报价、样品、注册或招标页面修改内容后返回，应用会询问是否放弃修改。选择“继续编辑”会保留当前输入；选择“放弃修改”才会退出。客户、联系人和新增报价把全部字段恢复为进入页面时的值后可直接退出。保存成功、确认删除以及进入附件后返回不会重复提示。
- **弹窗显示**：确认、删除、退出保护和编辑纠错弹窗使用一致的可读宽度；在窄屏设备上会自动缩小并保留屏幕边距。
- **校验错误定位**：订单、跟进、项目或招标保存未通过时，页面会自动滚动到首个需要处理的字段；文本字段会直接获得输入焦点。招标错误位于“资格核验”或“授权与风险”时，应用会先展开对应区块。
- **附件**：可在客户、跟进、项目和各业务记录中添加文件；报价、样品、注册和招标也可从各自维护页直接进入附件。点文件可预览图片或调用系统应用打开，长按/菜单可删除。

删除客户或业务记录会同时清理其关联记录和附件，且无法撤销。维护页会要求二次确认；若个别附件文件暂时清理失败，应用会提示并在下次启动重试。

### 4.3 客户列表快捷筛选

搜索框下方的 **逾期、A 级、报价停滞、样品停滞、长期沉默** 是一按即用的快捷筛选，再点一次即可取消。需要组合客户、项目、日期和异常条件时，再打开“高级筛选”；从漏斗异常进入客户列表会自动带入对应异常筛选。

## 5. 项目与开发漏斗

项目是“某客户的某个产品机会”。建议至少填写项目名称、产品/型号、当前销售阶段、下一步行动和下次跟进日期。

常见销售阶段包括：新线索、已建立联系、需求确认、已报价、价格谈判、样品准备、样品测试、注册进行中、招标准备、等待订单、已成交、暂停、流失。项目还可设置投入状态，用于决定是否继续投入。

在“漏斗”页面可查看：客户总数及 A/B/C/D 数量、各阶段项目数、本周跟进数、未来三个月预计成交金额、加权预计金额、已成交金额，以及长期沉默、需要内部支持、注册到期、招标临近截止和近期复购等异常。带箭头的统计项可点击下钻到明细。

## 6. 记录跟进

1. 从客户详情点击“记录跟进”。如果客户还没有项目，请先创建项目。
2. 选择跟进项目，填写客户反馈、项目阶段和下一步行动。
3. 可补充跟进内容、跟进方式和联系人。
   联系人和“客户态度”（积极、一般、评估中、拖延、已读未回、明确拒绝）是辅助字段；历史记录同时保存当时负责人快照。
4. 在“后续安排”选择“安排下次”，使用“明天”“三天后”“一周后”“一个月后”或“自定义”；也可以选择“暂不跟进”并填写暂停原因。
5. 保存。

保存后，系统会同步项目的最近跟进日期、最新反馈、当前阶段、下一步行动和下次跟进日期，并按计划生成提醒。每次联系都应新增一条记录，以保留完整历史。

填写跟进内容后如果误触导航栏返回或 Android 系统返回，应用会先询问是否放弃修改；选择“继续编辑”可保留当前输入。

## 7. 业务节点录入

在客户详情的项目卡片或业务区点击新增：

- **报价**：填写报价编号、数量和总金额；价格变化使用“基于此报价新增版本”，收悉、反馈、下次跟进和结果在报价行中点击维护。维护页可直接查看附件数量、管理附件或删除报价。
- **样品**：新增时填写样品型号和数量；点击已有样品可推进准备、寄出、签收、测试、通过或失败，并填写测试结果和下一步行动。已有样品的型号和数量在节点维护页锁定，如有变化请新增样品记录。维护页可直接管理附件或删除样品。
- **注册**：维护资料状态、注册状态、日期、费用、阻碍和下一步行动。
- **注册与招标**：长表单先显示基本信息，资料、资格和授权等低频字段可按区块展开或收起，展开/收起不会清除已填写内容；保存按钮固定在屏幕底部。已有记录可在页面顶部直接管理附件或删除。招标需维护截标日期、标书、投标资格、主体、保证金、风险和授权；选择高风险或填写底价支持后，风险区会自动打开，并且必须勾选“我已确认风险”后才能保存。
- **退出保护**：客户、联系人、项目、跟进、订单、报价、样品、注册和招标页面在有未保存修改时会拦截导航栏返回和 Android 系统返回。需要保留内容时选择“继续编辑”；确认不保存时选择“放弃修改”。客户、联系人和新增报价恢复进入页面时的值后不会询问。
- **保存校验**：订单、跟进、项目和招标存在无效输入时，会自动定位首个错误；招标折叠区会按需展开，不必手动逐段查找。
- **订单**：填写订单号、PI/PO、日期、金额和币种，并分别维护付款、生产和发货状态；金额前缀会跟随币种变化，不会固定显示人民币符号。可推进订单状态、取消或删除订单。

业务节点会参与今日任务和漏斗异常计算。保存后如未立即看到变化，可下拉刷新页面。

## 8. 今日任务与提醒

### 8.1 处理任务

“今日”自动显示逾期和今天到期的任务，并分别标出数量。点击任务可进入对应客户详情；在任务卡片底部可选择完成或取消。取消不会删除历史记录。

任务通常包含客户、国家、项目/产品、最近反馈、跟进原因、沟通方向、下一步行动、负责人和到期时间。暂停、流失和已关闭项目不会持续生成高频任务。

### 8.2 首次开启提醒

在“我的”依次检查 **提醒权限**：通知权限、精确闹钟、电池优化、自启动和后台弹出界面。不同手机品牌的设置名称可能不同；按页面提示进入系统设置并返回应用。

可在 **提醒自检** 中安排一条测试提醒，确认设备能按时响铃；在 **提醒记录** 中查看计划时间和实际触发时间。

若提醒不响：

1. 确认系统通知和提醒权限已允许。
2. 关闭应用的电池优化限制，允许自启动和后台运行。
3. 检查系统的“勿扰模式”、静音和通知渠道音量。
4. 回到“提醒自检”重新测试；设备重启后打开一次应用，让未来提醒重新建立。

## 9. 附件

在客户、跟进、项目、报价、样品、注册、招标或订单对应的“附件”入口中：

1. 点击添加附件。
2. 从系统文件选择器选择文件并等待保存完成。
3. 点击附件名称查看图片预览，或调用系统中支持该格式的应用打开。

附件保存在应用私有目录中，并包含在完整备份内。若原文件被系统清理，列表会显示“文件已丢失”；可重新添加。删除附件前请确认，删除记录后文件清理可能在下次启动重试。

## 10. Excel 导出

进入 **我的 → Excel 导出 → 生成并分享 Excel**。生成的工作簿包含四张业务工作表：

1. 今日任务及看板
2. 客户及项目
3. 跟进记录
4. 业务追踪（报价、样品、注册、招标、订单等）

客户及项目表会附带客户编号、类型、负责人和招投标能力；跟进记录会附带联系人、客户态度和负责人快照。

生成后会打开系统分享面板，可保存到文件、发送给自己或用表格应用打开。Excel 用于查阅和分析，不是应用的主数据源；在 Excel 中修改不会自动回写应用。

## 11. 客户/联系人导入

进入 **我的 → 客户/联系人导入**，按页面的两步操作：先点击“下载导入模板”并填写资料，再选择文件预览。支持 UTF-8 CSV 和 Excel 文件的第一张工作表。

客户名称是必填项；客户阶段和客户等级请填写说明书中的中文值。客户编号匹配已有客户时会更新客户资料，没有客户编号时，系统会尝试按“公司 + 国家/地区”识别唯一已有客户。联系人按客户和联系人姓名匹配，匹配到时更新，否则新增。

选择文件后先查看预览。问题会按源文件行号归组，并显示错误字段和当前值；点击“修正本行”可直接修正名称、编号、邮箱、阶段或等级，确认不需要的数据可选择“不导入此行”。每次修正或排除后都会重新校验全部保留行，仍有问题时不能确认导入。

确认前建议先完成一次完整备份。导入完成后可点击“查看客户列表”核对结果。导入只覆盖客户和联系人，不会创建项目、跟进、报价或订单。

## 12. 备份与恢复

### 11.1 备份

进入 **我的 → 备份与恢复 → 备份并分享**，在系统分享面板中把备份文件保存到安全位置。备份包含数据库、客户/项目/跟进/业务数据、附件文件、版本信息和校验信息。

建议在换机、系统升级或批量导入前先备份，并至少保留一份不在本机的副本。

### 11.2 恢复

1. 进入“备份与恢复”，点击“选择备份并恢复”。
2. 选择此前生成的备份文件，等待校验完成。
3. 页面提示“将在下次启动时生效”后，完全退出并重新打开应用。

恢复会替换当前数据库及附件，请先备份当前数据。恢复期间不要删除备份文件或强制结束应用。

## 13. 示例数据

进入 **我的 → 示例数据** 可导入 9 条可编辑的业务示例。导入不会修改现有客户；确认不再需要时点击“撤销全部示例数据”，只会删除这批示例及其业务记录，不影响正式客户。

## 14. 常见问题

**看不到今天的任务**：确认项目不是暂停、流失或已关闭，并检查跟进记录是否填写了下次跟进日期；下拉刷新“今日”。

**无法新增跟进**：客户必须先有项目；请返回客户详情创建项目。

**金额显示不符合预期**：报价、项目和订单金额按数据库的最小货币单位保存，录入前确认当前字段提示和币种。

**Excel 或备份分享失败**：检查设备存储空间和系统分享服务，稍后重试；备份失败时不要删除现有备份。

**附件打不开**：确认设备有支持该文件格式的应用；若提示文件已丢失，请重新添加附件。

## 15. 数据安全建议

- 不把唯一一份数据留在手机上，定期执行完整备份。
- 更换设备前先备份，恢复后抽查客户数、项目数、跟进记录和附件。
- 删除客户、订单或附件前先确认影响范围。
- 应用为单人本地工具，不提供多人同步、账号权限或云端灾备。
