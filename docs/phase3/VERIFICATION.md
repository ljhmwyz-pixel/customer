## 4. 模拟器人工检查

已安装并启动 release APK，保留既有数据完成以下操作：

1. 切换今日、客户、漏斗和我的四个底栏页面。
2. 查看客户列表和详情，执行名称搜索、阶段筛选、标签筛选及组合筛选。
3. 仅填写名称创建客户 `emulator acceptance customer 2026－08－05`。
4. 新增跟进 `emulator acceptance followup 2026－08－05`，选择「暂不跟进」，确认没有
   创建下一计划。
5. 查看提醒权限、提醒记录、提醒自检和暂不可用的备份入口。
6. 检查应用进程日志和 Android crash buffer；未发现应用相关 fatal、exception、error、
   `FlutterError` 或 overflow。

漏斗页当前为空是阶段 4 占位行为，不属于阶段 3 缺陷；订单、漏斗和附件按既定计划在
阶段 4 实现。
