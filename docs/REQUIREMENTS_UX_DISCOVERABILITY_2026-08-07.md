# 本期需求：首次使用与高频操作可发现性优化

日期：2026-08-07

## 目标

让新用户打开应用后能立即找到最常用的客户动作，并让批量导入流程在每一步都有明确反馈和去向。

## 范围

- 今日首页增加高频操作区：新建客户、客户列表、客户/联系人导入。
- 导入页面改为清晰的两步流程：下载模板 → 选择文件。
- 导入页面显示文件格式错误、预览统计、错误行和确认状态。
- 导入成功后提供“查看客户列表”入口。
- 保持现有路由和客户详情行为不变。

## 不在本期

- 不在本期把客户详情 1525 行页面拆成四个页签。
- 不改变数据库结构、导入字段和重复匹配规则。
- 不新增云同步、账号、AI 或外部渠道自动化。

## 验收标准

1. 首页无论是否有任务，都能在首屏看到三个高频操作。
2. 导入页面首次打开时，模板下载是第一主步骤，选择文件是第二主步骤。
3. 非 `.csv` / `.xlsx` 文件在选择后立即显示明确错误，不进入解析等待。
4. 导入预览必须显示总行数、问题数和确认按钮状态。
5. 导入成功后能一键进入客户列表，且页面提示新增/更新数量。
6. 取消文件选择、分享失败和解析失败都不会卡住页面。
