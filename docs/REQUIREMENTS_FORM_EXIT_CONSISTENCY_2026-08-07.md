# 本期需求：核心表单退出一致性与样品编辑语义

日期：2026-08-07

## 背景

上一期已为报价结果、样品、注册和招标页面增加未保存修改保护，但订单、跟进和项目仍可能因误触返回丢失大量输入。样品维护页还存在更直接的误导：编辑已有样品时，型号和数量看起来可以修改，但“保存节点”只保存状态、测试结果和下一步行动。

## 目标

- 消除样品维护页不可持久化字段的错误可编辑暗示。
- 将同一套未保存修改保护扩展到订单、跟进和项目表单。
- 保持现有保存、校验、路由、数据库和业务规则不变。

## 交互规则

### 样品维护页

1. 新增样品时，型号和数量继续可编辑并参与保存。
2. 编辑已有样品时，型号和数量显示原值但不可编辑。
3. 编辑页显示简短锁定说明：当前页面只推进样品节点；型号或数量变化应新增样品记录。
4. 状态、测试结果和下一步行动继续可编辑。
5. 只读字段不会触发未保存修改确认。

### 订单、跟进与项目

1. 页面加载完成且用户未修改时，导航栏返回和 Android 系统返回直接退出。
2. 文本、下拉、分段选择、开关、快捷日期或日期时间发生变化后，返回显示现有“放弃未保存的修改？”确认弹窗。
3. “继续编辑”保留所有输入；“放弃修改”退出当前页面。
4. 订单号自动生成、订单/项目异步回填、跟进默认选择首个项目或联系人，不计为用户修改。
5. 保存成功后直接回到客户详情，不重复显示退出确认；保存失败继续保持保护。
6. 项目采用供应商建议属于用户修改，必须触发保护。

## 不在本期

- 不修改样品、订单、跟进或项目的服务 API 和数据库结构。
- 不支持直接修改已有样品的型号和数量。
- 不扩展到客户、联系人和新增报价表单。
- 不实现自动草稿或“修改后恢复原值”检测。
- 不包含 OnePlus/ColorOS 真机验证。

## 验收标准

1. 样品新增页型号和数量可编辑，编辑页两字段只读且有锁定说明。
2. 订单、跟进、项目的文本及非文本控件均接入退出保护。
3. 异步加载和默认值不会产生误提示。
4. 保存成功不被退出保护拦截。
5. 聚焦 UT、全量 UT、静态分析、release APK 构建和 Android 模拟器安装启动验证通过。
6. 仓库说明书与应用内使用说明同步。
