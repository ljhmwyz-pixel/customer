# 阶段 2B 验收记录　ColorOS 真机可靠性

创建于 2026-08-04　　目标设备：一加 13 / ColorOS 15

## 1. 当前结论

**状态：待真机验收。**

阶段 2A 已在 Android 模拟器完成提醒链路、通知操作、深链、重启恢复与覆盖安装验证，
但模拟器无法复现 ColorOS 的自启动、后台冻结、Doze 和省电策略。本文件只定义真机步骤
和记录格式；在连续三天的实测完成前，不得把阶段 2B 标为通过。

阶段 3 可以并行开发并进行自动化及模拟器验证，但其发布验收仍需保留本阶段的真机门槛。

## 2. 验收前设置

在「我的 → 提醒权限」逐项处理，并记录实际菜单名称和截图：

1. 通知权限：允许通知，锁屏通知内容可见。
2. 闹钟和提醒：允许应用设置闹钟与提醒。
3. 电池优化：将应用设为不优化或允许后台高耗电。
4. 自启动：在 ColorOS 应用管理中允许自启动及关联启动。
5. 最近任务：不锁定应用，以覆盖普通用户从任务列表划掉应用的场景。

若厂商专用页面无法打开，应确认应用已回退到系统「应用详情」，再按页面中的图文步骤
手动查找。记录跳转结果，不得把「打开了设置页」等同于权限已开启。

## 4. 必测场景

以下场景均需至少命中一条提醒；同一条提醒可同时覆盖多个条件，但证据必须能辨认条件：

| 场景 | 操作 | 通过标准 | 状态 |
|---|---|---|---|
| 锁屏息屏 | 排期后锁屏，保持息屏至少 30 分钟 | 锁屏通知出现且偏差 ≤ 60 秒 | 待验收 |
| 清理最近任务 | 从最近任务划掉应用，不使用 `force-stop` | 进程退出后提醒仍出现 | 待验收 |
| 飞行模式 | 排期成功后开启飞行模式 | 无网络时提醒仍出现，操作可落库 | 待验收 |
| 重启 | 排未来提醒后重启，不主动打开应用 | 重启后未来提醒自动恢复 | 待验收 |
| 夜间充电 | 息屏充电过夜，安排次日提醒 | 次日提醒正常且偏差 ≤ 60 秒 | 待验收 |
| 非充电深度待机 | 电量充足，息屏静置至少 2 小时 | Doze/省电状态下提醒正常 | 待验收 |
| 通知正文 | 点击通知正文 | 打开 `/customers/:id?planId=...` 对应详情 | 待验收 |
| 通知操作 | 分别验证「已完成」「推迟一天」 | 状态、时间和重新排期正确 | 待验收 |

`adb shell am force-stop` 会让 Android 取消应用的 PendingIntent，不等价于从最近任务划掉，
不得用它作为「强杀后仍提醒」的验收方式。

## 5. 失败时采证

保留以下信息后再重新打开应用：设备型号、ColorOS 版本、应用版本、电量与充电状态、
计划和实际时间、权限页截图、锁屏通知截图、提醒日志，以及可用时的 `dumpsys alarm`、
`dumpsys notification` 和 logcat。失败记录不得删除或用下一次成功覆盖。

## 6. 通过条件

连续三天记录完整、每天至少两条提醒、所有必测场景完成，且每条有效提醒偏差均不超过
60 秒，才可将本文件状态改为「通过」。若任一项未完成，结论保持「待真机验收」或
「不通过」，并依据 `docs/phase2/PLAN.md` 的降级顺序调整提醒实现后重新计时三天。
