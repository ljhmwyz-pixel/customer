# 本期需求：客户与联系人批量导入 MVP

日期：2026-08-07

## 目标

让用户可以从标准 Excel 或 CSV 文件批量迁移客户和联系人，降低从旧表开始使用本应用的门槛，同时保证重复识别、字段校验和失败回滚可控。

## 范围

- 支持 `.xlsx` 和 UTF-8 `.csv` 文件。
- 支持一个工作表/CSV 文件中的客户列，以及可选的联系人列。
- 一行代表一个客户；同一客户的多个联系人使用分号分隔，或使用独立联系人文件按客户编号关联。
- 支持新增客户；客户编号匹配已有客户时允许更新客户资料。
- 联系人按客户编号和姓名匹配，匹配到时更新，否则新增。
- 导入前展示解析预览、错误行和新增/更新/跳过统计。
- 写入前提醒用户先备份，整批写入使用数据库事务。
- 导入结果可查看成功和失败数量，失败行不影响成功行之外的事务结果。

## 不在本期

- 不导入项目、跟进、报价、样品、注册、招标和订单。
- 不把现有四表导出文件直接作为回写格式。
- 不做云端导入、邮件/WhatsApp 自动归档或后台同步。

## 模板字段

必填：`客户名称`

客户字段：`客户编号`、`客户名称`、`公司`、`国家/地区`、`客户类型`、`负责人`、`电话`、`微信`、`地址`、`来源`、`备注`、`客户阶段`、`客户等级`、`招投标经验`、`投标资格`、`投标主体`、`当地团队`、`资金状态`

联系人字段：`联系人姓名`、`联系人职位`、`联系人电话`、`联系人邮箱`、`联系人 WhatsApp`、`沟通偏好`、`是否决策人`、`联系人备注`

## 验收标准

1. 缺少客户名称的行在预览中标红并不能导入。
2. 客户编号优先作为更新键；没有编号时以公司和国家/地区组合提示潜在重复。
3. 同一文件内重复客户编号直接报错，不静默覆盖。
4. 联系人没有可归属客户时，该行失败并显示原因。
5. 日期、金额和业务状态字段不在本期导入范围内，不产生隐式业务记录。
6. 导入过程中任意数据库异常时整批回滚。
7. 导入入口位于“我的”首屏可见，并可从页面下载模板。
