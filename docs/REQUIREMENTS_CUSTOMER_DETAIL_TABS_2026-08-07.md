# 本期需求：客户详情四页签

日期：2026-08-07

## 目标

把客户详情从单一长页面整理成“概览、项目、业务、动态”四个明确视图，减少滚动和寻找成本，同时保持记录跟进与快捷新增动作直接可达。

## 信息分组

- 概览：客户摘要、客户资料、快捷操作、联系人。
- 项目：项目阶段、投入状态、替代建议、金额和下一步行动。
- 业务：报价、样品、注册、招标和订单；按所属项目分组。
- 动态：跟进计划和历史跟进记录。

## 交互规则

1. 默认打开概览。
2. 从提醒深链进入并携带计划编号时，默认打开动态。
3. “记录跟进”悬浮按钮在四个页签始终可见。
4. 概览中的联系人、项目、业务和订单快捷操作保持不变。
5. 每个页签独立滚动，并支持下拉刷新。
6. 业务页没有项目时，引导创建项目；没有业务记录时仍保留新增入口。

## 不在本期

- 不修改数据库、业务状态和提醒规则。
- 不重新设计各业务表单。
- 不增加新的业务类型或团队协作能力。

## 验收标准

1. 320px 宽度下四个页签文字完整、无重叠。
2. 切换页签不会丢失客户数据或触发重复写入。
3. 项目页不再嵌套显示业务记录。
4. 业务页能进入报价结果、样品、注册、招标和订单维护页面。
5. 动态页能显示并高亮提醒深链指定的计划。
6. 现有新增、编辑、删除、状态推进和附件入口保持可用。
