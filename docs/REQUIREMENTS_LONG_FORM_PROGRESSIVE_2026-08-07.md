# 本期需求：注册与招标表单渐进展开

日期：2026-08-07

## 目标

降低注册、招标新增和编辑的首屏认知负担，让用户先完成当前阶段最重要的信息，再按需要展开低频字段；保持所有已有字段、校验和保存结果不变。

## 交互规则

- 注册表单分为“基本信息”“资料与时间”“推进与行动”。新增时基本信息和推进与行动展开，资料与时间折叠；编辑时根据已有状态保持相同分组结构。
- 招标表单分为“基本信息”“资格核验”“授权与风险”。基本信息默认展开，资格核验和授权与风险默认折叠。
- 招标用户选择高风险，或填写授权/底价支持后，授权与风险区自动展开；风险确认紧邻触发字段显示。
- 折叠只改变可见性，不清除已填写值；保存时提交全部字段。
- 现有稳定 `ValueKey` 保持不变，附件/删除操作区仍位于编辑页顶部，底部保存按钮保持固定。
- 320px 宽度和键盘弹出时不产生横向溢出；区块标题和展开按钮保持可读、可点击。

## 不在本期

- 不修改数据库、服务 API、状态机或任务规则。
- 不改变订单、项目和跟进表单。
- 不自动替用户选择状态、日期或风险确认。

## 验收标准

1. 注册新增首屏显示基本信息和下一步行动，资料与时间默认折叠。
2. 招标新增首屏显示基本信息，资格核验和授权与风险默认折叠。
3. 展开后每个现有字段仍可编辑，保存测试和风险校验测试继续通过。
4. 高风险/授权/底价触发后风险区自动展开并显示确认控件。
5. 全量 UT、静态分析和 release 构建通过。
